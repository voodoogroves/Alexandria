# Alexandria

The Pharos: the light that points to the right shelf. Knowledge for personal work.

- `memory/`: curated, topical notes (source of truth), one doc per topic in `memory/<type>/`, with frontmatter. Format and checks: Rhodes `docs/memory-system.md`
- `output/`: generated material (never a source of truth)
- `reference/`: offline third-party references, gitignored and local to this machine. `fo4-ck-wiki/` is a Creation Kit wiki snapshot (file name dated 2021-05-20)
- `historical/`: archived ideas and superseded work, kept for reference (never a source of truth; may be purged later). Organised by project, e.g. `historical/regalia/`.

Hub and work surface live in Rhodes.
