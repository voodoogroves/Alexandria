# Alexandria

The Pharos: the light that points to the right shelf. Knowledge for personal work.

- `memory/`: curated, topical notes (source of truth)
- `output/`: generated material (never a source of truth)
- `historical/`: archived ideas and superseded work, kept for reference (never a source of truth). Organised by project, e.g. `historical/regalia/`.

Hub and work surface live in Rhodes.
